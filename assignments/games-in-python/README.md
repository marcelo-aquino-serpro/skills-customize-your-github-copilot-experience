
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Criar um jogo da forca em Python em que o jogador adivinha letras para revelar uma palavra secreta. A atividade pratica manipulação de strings, loops, condicionais e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar a lógica principal do jogo

#### Descrição

Crie a estrutura do jogo para escolher uma palavra aleatória, receber palpites do usuário e mostrar o progresso da palavra com letras descobertas e espaços ocultos.

#### Requisitos

O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Aceitar palpites de letras do usuário
- Exibir o progresso atual da palavra no formato `_ _ _`

### 🛠️ Controlar vitória, derrota e tentativas

#### Descrição

Implemente as regras de encerramento do jogo, incluindo contagem de tentativas incorretas e mensagens finais para cada resultado.

#### Requisitos

O programa concluído deve:

- Rastrear as tentativas incorretas restantes
- Encerrar quando a palavra for adivinhada ou as tentativas esgotarem
- Exibir mensagens de vitória e derrota ao final da partida
