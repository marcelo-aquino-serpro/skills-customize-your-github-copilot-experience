# 📘 Assignment: CSV Mini Dashboard

## 🎯 Objective

Build a beginner-friendly mini dashboard using Python to load a CSV file, calculate simple indicators, and create charts that communicate basic insights.

## 📝 Tasks

### 🛠️ Load and Explore the Dataset

#### Descrição
Open the provided CSV file and inspect its structure so you understand what each column represents.

#### Requisitos
O programa concluído deve:

- Load `sales_data.csv` with pandas
- Print the first 5 rows
- Print basic information about the dataset (`shape`, column names, and data types)


### 🛠️ Calculate Core Indicators

#### Descrição
Compute a small set of business-style indicators from the dataset.

#### Requisitos
O programa concluído deve:

- Calculate total revenue (`sum` of `revenue`)
- Calculate average revenue per sale
- Identify the product category with the highest total revenue


### 🛠️ Build and Save a Mini Dashboard

#### Descrição
Create two simple charts and summarize what they show.

#### Requisitos
O programa concluído deve:

- Create one bar chart of revenue by category
- Create one histogram of order values
- Save both charts as image files (`revenue_by_category.png` and `order_value_distribution.png`)
- Print at least 2 short insights based on the indicators and charts
